01 · The kit

Foundations Kit

48 parts · 81 files · one line to start

Your offer, pricing, weekly numbers, memory and backup, as files Claude reads first. It opens with The Operator Check: ten questions from your own records, about five minutes, then a plan for your next four weeks.

How to start

  1. Download the zip and unzip it.
  2. Give the folder to Claude, or the AI agent you use.
  3. Paste this one line:

Read KIT-MANIFEST.md in this folder and follow its notice to the recipient's agent.

Your agent needs to read and write files in that folder and run a command. The kit has it check that first.
